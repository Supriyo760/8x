# User Stories — Amazon Re-imagined

## 1. Discovery & Search Stories
- **US-01**: As a shopper, I want to search for items using keywords or department categories so that I can quickly locate relevant products.
- **US-02**: As a price-sensitive buyer, I want to filter products by price range and view active discount tags so that I can shop within my budget.
- **US-03**: As a Prime subscriber, I want to toggle a "Prime Only" filter so that I only see items with guaranteed fast, free delivery.
- **US-04**: As a researcher, I want to filter by ratings (4 stars & up) and sort by customer reviews so that I can find high-quality products without guessing.
- **US-05**: As a browsing customer, I want to open a "Quick-Peek Drawer" from any card so that I can review specifications and color options without losing my scroll position.

## 2. Product Evaluation Stories
- **US-06**: As an informed buyer, I want to read an "AI Review Digest" so that I can instantly understand the consensus pros, cons, and durability of a product without scrolling through 500 reviews.
- **US-07**: As a customer deciding between two laptops or headphones, I want to add them to a "Comparison Dock" so that I can view their specs side-by-side with differences highlighted.
- **US-08**: As a buyer, I want to click through multiple product angles and zoom in on details so that I can assess build quality and finishes.
- **US-09**: As a customer, I want to choose between different colors and storage capacities so that the price and stock status update in real time.

## 3. Cart & Purchasing Stories
- **US-10**: As a shopper, I want to add items to my cart and see a slide-out drawer so that I get immediate confirmation and view my subtotal without navigating away.
- **US-11**: As a customer near the free shipping minimum, I want to see a live "Free Shipping Progress Bar" so that I know exactly how much more to add to qualify.
- **US-12**: As an urgent shopper, I want to use "1-Click Buy Now" so that I can bypass lengthy checkout steps when I need an item immediately.
- **US-13**: As a careful buyer, I want a streamlined 2-step checkout flow so that I can enter/verify my shipping address and select delivery speeds cleanly.

## 4. Post-Purchase Stories
- **US-14**: As a buyer who just ordered, I want an instant order confirmation with a realistic Amazon Order ID so that I have a clear record of my purchase.
- **US-15**: As a customer awaiting delivery, I want to view an interactive tracking stepper in "My Orders" so that I can see the item's live status (Ordered → Shipped → Out for Delivery).
- **US-16**: As a buyer who changed their mind, I want to cancel an order before it ships so that my mock payment is refunded instantly.
